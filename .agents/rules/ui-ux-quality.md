# Master UI/UX Quality Rules (CreditWise)

The application must feel:
- considered
- restrained
- premium
- editorial
- trustworthy
- spacious
- intentional
- easy to understand

It must NOT feel:
- vibe-coded
- template-generated
- AI-generated
- like a generic SaaS dashboard
- like a hackathon landing-page template
- overloaded with cards
- overloaded with rounded containers
- overloaded with gradients
- overloaded with animations

## Visual Rules

Do NOT use:
- purple gradients
- generic blue/purple AI gradients
- excessive glassmorphism
- excessive blur
- pill-shaped UI everywhere
- giant rounded cards containing smaller rounded cards
- unnecessary shadows
- fake statistics
- fake testimonials
- fake reviews
- fake logos
- fake metrics
- emoji icons
- decorative UI that has no purpose
- excessive badges
- excessive chips
- excessive floating elements
- huge text blocks
- vague marketing copy
- meaningless section headings
- unnecessary animations
- scroll-jacking
- excessive parallax
- giant glowing effects

Avoid the visual pattern:
`big rounded container -> smaller rounded container -> smaller rounded container -> pills -> badges -> icons -> gradient`

## Typography

Prefer:
- strong editorial hierarchy
- large but controlled headlines
- comfortable line lengths
- restrained weights
- clear contrast between primary and secondary text
- generous whitespace
- Do not make everything bold
- Do not make every heading huge

## Spacing

- Whitespace is part of the design.
- Do not fill empty space just because it exists.
- Do not add elements simply to make a section look "complete."

## Content

- Use concise, human language. Every piece of copy should communicate something useful.
- Do NOT write generic AI copy ("Unlock your financial potential", "Experience smarter financial freedom", "Revolutionize your spending", "Take control of your financial journey").
- CreditWise helps people find credit cards that fit their existing spending. Never encourage people to spend more.
- Use: "Don't spend more. Get more back." and similar clear language when appropriate.

## Interaction

Animations should have a reason.
- Prefer: subtle transitions, pointer-reactive details, restrained reveal animations, natural hover states, smooth state changes.
- Avoid: dramatic entrance animations, excessive bouncing, unnecessary floating, exaggerated scale effects, animation on every element.

## Accessibility

- Keyboard navigation
- Visible focus states
- Sufficient contrast (WCAG AA)
- Semantic HTML
- Useful alt text
- Reduced-motion support
- Mobile-friendly interaction

## Responsiveness

- Do not treat mobile as an afterthought.
- Desktop can be the primary composition, but tablet and mobile layouts must be intentionally designed rather than simply stacked.

## Decision Rule

Before adding any component: "Does this improve the user's understanding or interaction?" If not, do not add it.
Before adding any visual effect: "Would a strong product designer actually use this here?" If not, don't add it.
Do not change existing sections unnecessarily. Preserve strong existing work.
CreditWise should feel like a real product designed by a strong product designer, not a website assembled by an AI.
