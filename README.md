# CardWise Insights

I want you to design and build a polished web application called "CardWise".

READ THIS ENTIRE PROMPT BEFORE IMPLEMENTING ANYTHING.

I will provide screenshots from Stripe and Ramp as visual references. These screenshots are NOT templates to copy. They are references for design quality, layout, typography, spacing, product presentation, and motion.

============================================================

1. PROJECT

============================================================

CardWise is a modern credit-card discovery, recommendation, comparison and education platform.

The user should be able to:

1. Explore credit cards.

2. Search, filter and sort cards.

3. View detailed information about individual cards.

4. Answer a short questionnaire about their spending preferences.

5. Receive personalized card recommendations.

6. Understand why a card was recommended.

7. Compare 2–3 cards side by side.

8. Estimate rewards based on their spending.

9. Read educational articles about credit cards.

10. Create a CardWise account.

11. Log in and log out.

12. View a profile.

13. Save/favorite credit cards.

This is a college mini-project.

My teacher has instructed me to integrate the requirements from Assignments 1, 2, 3 and 4 into this single application instead of making separate assignment websites.

Therefore:

CARDWISE MUST BE ONE COHERENT APPLICATION.

Do NOT create unrelated assignment demo pages.

All assignment requirements should be naturally integrated into the real CardWise product.
